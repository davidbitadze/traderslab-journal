# ენების დამატება

1. დააკოპირე `ka.py` ახალი სახელით (მაგ. `ru.py`).
2. შეცვალე `CODE`, `NAME`, `FLAG` და თარგმნე `STRINGS`-ის მნიშვნელობები (გასაღებები არ შეცვალო).
3. ენა მენიუში თავისით გამოჩნდება; კოდში არაფერი უნდა დაემატოს.
4. დაკარგული გასაღები ავტომატურად ქართულიდან (ka) აიღება. რა გამოგრჩა, ნახე:

```
python -c "import i18n; print(i18n.missing_keys())"
```

შენიშვნა: `views/add_trade_modal.py`, `views/admin.py`, `views/journal.py` და ზოგ სხვა ფაილში ჯერ კიდევ არის
`lang == "en"` ტიპის ჩაშენებული ტექსტები. ახალ ენაზე ისინი ქართულად/ინგლისურად დარჩება, სანამ `t("გასაღები")`-ზე არ გადავა.
