# მიგრაციის გაშვება (ერთხელ)

1. გახსენი `001_security_and_admin.sql` და ზემოთ `CHANGE_ME@example.com` შეცვალე შენი ელფოსტით
   (იმით, რომლითაც აპში შედიხარ). ეს ელფოსტა მხოლოდ ბაზაში რჩება, კოდსა და GitHub-ზე არსად ხვდება.
2. Supabase -> SQL Editor -> ჩააკოპირე მთელი ფაილი -> Run. შეგიძლია ხელახლაც გაუშვა, უსაფრთხოა.
3. დაუყოვნებლივ გაუშვი აპის ახალი კოდი (ძველი ადმინ-პანელი და პარამეტრების ჩაწერა ახალ წესებს ვერ მოერგება).
4. Authentication -> Providers -> Email: "Confirm email" ჩართული უნდა იყოს (ადმინის ამოცნობა ელფოსტაზეა დაფუძნებული).
5. არასავალდებულო AI ანალიზისთვის Streamlit-ის Secrets-ში: `ANTHROPIC_API_KEY = "..."`
   (გასაღების გარეშე ფუნქცია გამორთულია; სატესტოდ `AI_DEMO_MODE = true`).

ადმინების/მენტორების დამატება და ამოღება შემდეგ პირდაპირ აპიდან: ადმინისტრაცია -> ადმინები და მენტორები.
